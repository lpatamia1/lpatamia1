# 🚀 Future Adventure (Java Terminal Game)

A short **text-based sci-fi adventure** where your choices decide your fate.  
Explore strange worlds, solve riddles, and meet mysterious creatures — all through the command line.

## 💡 Overview
- Choose-your-own-path gameplay  
- 6 unique endings  
- ASCII art scenes  
- 100% Java, runs directly in terminal  
- Replayable — different paths each time!

## 🎮 How to Play
Compile and run the game:

```bash
javac FutureAdventure.java
java FutureAdventure
